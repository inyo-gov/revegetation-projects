Purpose

What: A draft state-and-transition model (STM) for Laws Type E parcels: plant communities an ecological site can support, the transitions among them, and which changes are hard to reverse (Bestelmeyer et al. 2017).

Why: Cover and composition goals answer compliance; they do not name the starting state after irrigated agriculture ends. Stock desert STMs usually begin from native or lightly disturbed phases. Type E transfer parcels start as abandoned irrigated agriculture—often bare, with topsoil lost to wind after irrigation stops (Green Book Type A · Barren Lands – Abag). Without an explicit ABAG box, the model pretends recovery begins from intact scrub.

ICWD’s broader Owens STM work lives in stm (Green Book types as states within NRCS ecological sites; NMDS to test type separation).

flowchart LR

State Meaning
E – Irrigated ag Pre-transfer / failure-path revert
ABAG Precip-only barren after irrigation ceases; topsoil depleted; high wind erosion
Early seral / assisted Active revegetation; cover rising but not self-sustaining
Reference-like A Composition approaching Gravelly Loam arid reference mixes

Stock Gravelly/Loamy STMs still govern within-scrub phases (grazing, annuals, shrub dominance). ABAG is the Type E add-on.

## Purpose

**What:** A draft **state-and-transition model (STM)** for Laws Type E parcels: plant communities an ecological site can support, the transitions among them, and which changes are hard to reverse [@Bestelmeyer2017].

**Why:** Cover and composition goals answer *compliance*; they do not name the **starting state** after irrigated agriculture ends. Stock desert STMs usually begin from native or lightly disturbed phases. Type E transfer parcels start as **abandoned irrigated agriculture**—often bare, with topsoil lost to wind after irrigation stops (Green Book **Type A · Barren Lands – Abag**). Without an explicit **ABAG** box, the model pretends recovery begins from intact scrub.

ICWD’s broader Owens STM work lives in [`stm`](https://github.com/inyo-gov/stm) (Green Book types as states within NRCS ecological sites; NMDS to test type separation).

## Draft STM (Gravelly Loam 5-8" + ABAG)

```mermaid
flowchart LR
  E["Type E<br/>Irrigated agriculture"] -->|stop irrigation<br/>topsoil loss / wind| ABAG["ABAG state<br/>Abandoned ag · bare / eroded"]
  ABAG -->|planting, drip, nurse shrubs<br/>ATTO / ERNA / natives| EARLY["Early seral / planted<br/>low cover · high bare"]
  EARLY -->|recruitment + time<br/>no irrigation| REF["Reference-like Type A scrub<br/>ESD potential phases"]
  EARLY -->|fail / chronic drought<br/>or weed lock| ABAG
  REF -->|severe disturbance| ABAG
  E -.->|Plan failure path| E
```

| State | Meaning |
|-------|---------|
| **E – Irrigated ag** | Pre-transfer / failure-path revert |
| **ABAG** | Precip-only barren after irrigation ceases; topsoil depleted; high wind erosion |
| **Early seral / assisted** | Active revegetation; cover rising but not self-sustaining |
| **Reference-like A** | Composition approaching Gravelly Loam arid reference mixes |

Stock Gravelly/Loamy STMs still govern **within-scrub** phases (grazing, annuals, shrub dominance). **ABAG** is the Type E add-on.
